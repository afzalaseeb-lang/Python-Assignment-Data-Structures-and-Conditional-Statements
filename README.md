# Python-Assignment-Data-Structures-and-Conditional-Statements
This repository contains Python Assignment 2, focusing on fundamental Python concepts, including Lists, Dictionaries, Sets, Operators, and Conditional Statements.

## Topics Covered

### 1. Lists
- Creating lists with integer and string elements.
- Modifying lists using `append()`, `insert()`, `remove()`, `pop()`, and `extend()`.
- Sorting lists in descending order.
- Finding maximum, minimum, and sum of list elements.
- Accessing list elements using indexing and slicing.

### 2. Dictionaries
- Creating dictionaries with student names and marks.
- Accessing and modifying dictionary values.
- Adding new key-value pairs.
- Using `keys()`, `values()`, and `items()` methods.

### 3. Sets
- Creating sets and understanding duplicate element removal.
- Understanding set mutability and indexing limitations.
- Performing union and intersection operations.

### 4. Operators & Conditional Statements
- Using `IF`, `ELIF`, and `ELSE` statements.
- Applying logical and comparison operators.
- Developing a Performance Category Program.
- Validating user input within a score range of 0–10.
- Categorizing performance into Above Average, Average, and Below Average.

- Understanding Python's fundamental data structures.
